Verify it yourself

Check the seal on a published audit, then edit a local copy and see the verifier reject it. The seal covers the whole report, including the order of its receipts. A failed check identifies the affected report. It cannot pinpoint which receipt changed.

Verify a sealed audit in your browser

Check the bundled calendar outage report or select a local copy. The report stays in your browser. The public demo key checks the signature for this example. Anyone with that key can sign a report.

Whole-report seal: checking…

Use a shell with Git, curl, and Python 3.11 or newer. In a fresh working directory, set up the verifier first.

git clone https://github.com/aneesh2411/subpoena.git
cd subpoena
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .

1. Download the sealed audit

Use curl to save the Family two bookings audit from the live demo.

curl -fsSLO https://aneesh2411.github.io/subpoena/demo/data/audit-aud-clean-family-two-bookings.json

2. Verify the original

The export uses the public demo key subpoena-pages-demo (key ID 6508b98a7ace). Anyone with this key can produce a matching signature, so it demonstrates the seal check without establishing who published the report.

python scripts/verify_seal.py audit-aud-clean-family-two-bookings.json --key subpoena-pages-demo
echo "Exit code: $?"
Report 'aud-clean-family-two-bookings' receipts=3 integrity=intact authentication=authenticated (content and chain verified (signature verified))
VERDICT PASS (whole-report verification, 1/1 reports passed)
Exit code: 0

3. Verify a tampered copy

Change the provider on the first receipt in a local copy, keeping the original seal. The report line names the affected audit and the verdict line shows the overall failure.

python -c '
import json
import sys
from pathlib import Path

audit = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
audit["verdicts"][0]["claim"]["provider"] = "Dr. Edited"
Path(sys.argv[2]).write_text(json.dumps(audit), encoding="utf-8")
' audit-aud-clean-family-two-bookings.json tampered.json
python scripts/verify_seal.py tampered.json --key subpoena-pages-demo
echo "Exit code: $?"
Report 'aud-clean-family-two-bookings' receipts=3 integrity=altered authentication=authenticated (content does not match its hash: the report was altered)
VERDICT FAIL (whole-report verification, 0/1 reports passed)
Exit code: 1
